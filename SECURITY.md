# Security policy

Please report vulnerabilities through the repository's
[private vulnerability reporting form](https://github.com/LeonardSEO/bolacheck/security/advisories/new).
Private vulnerability reporting is enabled for this repository. Do not open a
public issue for a suspected vulnerability and do not include live credentials,
customer data, or evidence from a third-party system.

Supported releases and disclosure timelines will be documented after the
first tagged release. Until then, security fixes target the `main` branch.
